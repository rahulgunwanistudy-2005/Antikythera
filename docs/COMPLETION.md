# Build completion and research release gates

The software specification is implemented, integrated and tested. The scientific study remains in a collected/proposed stage until qualified independent annotation and coverage review.

| Brief component | Implemented software | Current empirical state |
| --- | --- | --- |
| Four source eras | Cleared-source download/parse adapters, exact spans and attribution | Four acquired sources, 2,972 unreviewed proposals |
| Claim extraction | English/German baselines and opt-in local structured model adapter | Semantic precision/recall not audited |
| Indication harmonisation | TF–IDF nearest-neighbour candidates and optional model adjudication | 150-item independent gold target remains unfilled |
| Identity | Versioned taxonomy candidates, expert drafts, distributions, dated calibration and reliability | Six modern-name candidate sets; no calibrated historical prior |
| External identity reference | Licensed article-grade importer with native ordinal categories | 141 assessments/50 names; Figshare file 11 unavailable |
| Evidence acquisition | PubMed and EuropePMC, caching, pagination, query plans and hash provenance | 69 unique PMIDs/75 query pairs, capped |
| Evidence grading | Conservative offline cue proposals, optional structured local model, human review | 75 offline verdict abstentions; no reviewed outcomes |
| Research effort | Dated annual-count acquisition with query provenance | 30 annual observations; incomplete history |
| Time machine | Freeze, three matched nulls, fame baseline, identity sampling, family bootstrap | Eligible reviewed cohort empty |
| Validation | Wilson scores, gold sampling, ECE, calendar test sets and overlap checker | Human audits and verified external overlap list pending |
| Era and lineage | Cumulative ablation, inherited/novel and category slices | No audited effect released |
| Sensitivities | In vitro, refutations, rematching and stated file-drawer grids | Available when reviewed matched data qualifies |
| Ranker | LightGBM, distinct mature calendar windows, calibration and ranking intervals | Fit/reload/predict verified on synthetic fixtures only |
| Forward shortlist | Search/region/hazard gates and conditional probability ensembles | No qualified leads released |
| User interface | Seven views, actual source/evidence queues, local reviews, results and exports | Private static snapshot and local writable workbench |
| Reproduction | Locked dependencies, offline pipeline, DuckDB, typed Parquet and static JSON | `make all` passes |
| Submission material | Ten-slide editable deck, Devpost copy and narrated/captioned video | Video 4 minutes 9 seconds |

A complete software build cannot truthfully supply human audit decisions or unavailable expert truth labels. The remaining scientific tasks are visible, actionable review work, not simulated completions. Completing the eligibility gates and independent audits automatically enables real results through the same pipeline.
