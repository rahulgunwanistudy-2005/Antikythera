# Dated evidence acquisition

Set `NCBI_EMAIL` (contact address) and optionally `NCBI_API_KEY` in the process environment. Run `python -m ledger.pubmed --query '"Colchicum autumnale"[Title/Abstract]' --output data/derived/pubmed-colchicum.json`. Search pagination refuses silent truncation above 10,000 results: partition by publication year. Requests are paced, retried, and cached; credentials never enter cache keys or stored request metadata. No live PubMed corpus was fetched during initial setup.

Use synonym-inclusive species queries, reviewed category MeSH/text queries and original-study pharmacology filters. Record the full query, synonym version and date coverage. `count(query, year=T)` returns a pre-freeze publication count; do not substitute present-day totals. Counts use publication date (`pdat`), and metadata parse uses journal issue year. Electronic versus print dates and delayed indexing need a declared sensitivity analysis. Abstracts are copyrighted and acquisition does not imply redistribution rights.

`grades.build_ledger` requires human-reviewed botanical-scoped grades. It stores both first relevant test and first in-vivo/clinical supporting year; in-vitro is opt-in. Compound discovery milestones in the demo catalog cannot be promoted into this ledger. Reviews should be used to locate original papers, not graded as original confirmations. Human audit remains outstanding. PubMed is not exhaustive for pre-1900 pharmacology: early freezes will need explicitly documented additional sources.

## Europe PMC fallback and proposal collection

`python -m scripts.collect --offline` uses existing caches only. `--fetch` authorises bounded public Europe PMC and GBIF retrieval. Default sample: six named modern species, three indication categories, five annual-date snapshots as specified by the CLI, and at most six records per category query. Inspect `collection.json` for the actual selected years, caps, query totals and truncation. `--species`, `--category`, `--max-records`, and repeatable `--effort-year` narrow collection. These are individual annual counts, not complete histories.

The official Europe PMC core response supplies MED/PubMed IDs, dates, publication types and abstracts without inventing an NCBI contact address. Raw abstract records remain in ignored local caches. Public evidence proposals include metadata, record hashes and paths but omit abstract text. API docs: https://europepmc.org/RestfulWebService . The query planner includes all twelve categories and both PubMed and Europe PMC syntax. Broad text matching is an acquisition plan, not a validated pharmacology filter. Source dates, relevance, study type and botanical scope require grading. Capped samples cannot determine first-ever confirmations or never-tested status. The model grading command is separately opt-in and never marks human review complete.
