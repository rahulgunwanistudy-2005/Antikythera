# Raw sources

This directory tracks retrieval scripts and a licence-status manifest. It deliberately contains no copied manuscript scans or modern copyrighted texts. Runtime caches are excluded from version control. A public-domain author does not imply that every scan, translation, transcription, or database licence is public domain.

Before download, verify edition, translator, scan terms and applicable jurisdiction. Modern Balkan supplementary tables require article-specific licence and attribution review; remove community-identifying details from exported research leads. Identity expert labels require their own licence check. Bibliographic abstracts retain their original copyright. Source discovery is not licence clearance.
